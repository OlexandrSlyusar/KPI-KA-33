## Мета

Навчитись враховувати тренд і сезонність при побудові математичних моделей часових рядів та будувати прогнози.

## Що зроблено

Для кожного ряду (logy = log(y), навчальна вибірка до 2007:12, перевірочна 2008:01–2008:08):

1. Тренди 1-го, 2-го і 3-го порядків.
2. АРІКС — модель для перших різниць dlogy зі складовими `ar(…)`/`ma(…)`; лаги АР — значущі лаги ЧАКФ dlogy, лаги КС — значущі лаги АКФ залишків, незначущі складові (Prob > 0,05) вилучаються по одній.
3. АР-модель для logy з явними лагами (`ls logy c logy(-1) …`).
4. АРКС-модель для logy (`ls logy c ar(…) ma(…)`).
5. Статичний (`fit`) і динамічний (`forecast`) прогнози на 8 кроків; RMSE, MAE, MAPE, коефіцієнт Тейла та його розклад Uᴹ, Uˢ, Uᶜ.

Обчислення відтворюють EViews у Python (EViews Student Lite не виконує програми); програма EViews — `code/eviews/lab4.prg`. Реалізацію перевірено на прикладі методички (агрегат M1 США): `verify_manual.py` відтворює 62 контрольні значення (рівняння trend1, trend2, ar4, ar4ma4, ar1, прогнози з таблиць 1–4, вікно прогнозу) — розбіжностей немає.

## Висновки

- Обидва ряди нестаціонарні: тренд і сезонність з періодом 12 місяців (АКФ dlogy на лагах 12, 24, 36: 0,90/0,81/0,74 для RSAFSNA і 0,87/0,83/0,81 для CURRNS).
- Тренди мають високий R², але прогнозують найгірше: не враховують сезонність, а екстраполяція полінома небезпечна (тренд 2-го порядку для CURRNS — MAPE 46 %).
- Статичний прогноз: найкраща АРІКС для обох рядів (MAPE у вихідних одиницях 1,43 % і 0,33 %).
- Динамічний прогноз: для CURRNS — АРІКС, для RSAFSNA — АР з лагами 1, 12, 13 (горизонт 8 місяців менший за сезонний лаг, тож сезонні складові беруть фактичні дані минулого року).
- Коефіцієнти ≈ 1 при першому і сезонному лагах вказують на одиничні корені, що обґрунтовує модель АРІКС.
