## Мета

Навчитися обчислювати оцінки коефіцієнтів рівнянь регресії, авторегресії, авторегресії з ковзним середнім (АРКС) та множинної регресії; пояснити призначення статистик, за якими визначається ступінь адекватності моделі процесу.

## Реалізація

- **EViews** (`code/eviews/`): програми для всіх чотирьох частин завдання — `lab3_dw.prg`, `lab3_arma.prg`, `lab3_mr.prg`, `lab3_pccf_armax.prg`.
- **Python** (`code/`): відтворення обчислень EViews (EViews Student Version Lite не виконує програми):
  - `ls` з усіма статистиками вікна EViews (R², Adjusted R², S.E., SSR, Log likelihood, F, Akaike, Schwarz, DW);
  - `ls y c ar(1..p) ma(1..q)` — нелінійний МНК (Марквардт) з бекастингом КС-складових за Боксом–Дженкінсом;
  - корелограма (`correl`): АКФ, ЧАКФ (Дарбін–Левінсон), Q-статистика Л’юнга–Бокса; описова статистика (`Histogram and Stats`);
  - `@movav`, експоненційне КС з ЛР №2, власні коефіцієнти при КС, ЧКФ.
- **Перевірка:** `verify_manual.py` відтворює 62 контрольні значення з рисунків і таблиць методичних вказівок (рис. 2, 9, А.3–А.11, табл. Б.3, DW = 1,22881) — розбіжностей немає.

## Висновки

- Програма DW дає еталонне значення 1,22881; розподіли обох рядів ненормальні (JB = 48,09 та 27,68), ряди мають тренд.
- Для обох рядів найкращим виявилось експоненційне КС з N = 5: rts1 — АРКС(2,5) з ЕКС по залишках АР(2) (Akaike 9,4923), rts1996 — АРКС(3,2) з ЕКС по y, підхід №2 (Akaike 5,0999, DW 2,0068).
- Рівняння з фіксованими коефіцієнтами при КС по y неадекватні (автокорельовані залишки, DW 0,49–1,62); КС системи EViews лише незначно покращує АР(p).
- Статична множинна регресія має сильну автокореляцію залишків (DW 0,46); модель ARMAX з лагами rts1 і регресорів усуває її (DW 1,95, Akaike 5,858 проти 7,022), а структура коефіцієнтів відповідає регресії з АР(1)-похибкою (ρ ≈ 0,89).
