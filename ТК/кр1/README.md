## Завдання 1. Період квантування та ПФ приведеної неперервної частини

**Умова:** об'єкт W₀(s) = 2 / ((s + 1)(s + 2)), точність ε = 0,01.

**1. Період квантування.** Канал u → y — це приведена неперервна частина (ЦАП + об'єкт), тому T₀ визначаємо методом B-характеристики:

```
T₀ ≤ ε / B_max,   B(ω) = ω·|W₀(jω)| = 2ω / √((ω² + 1)(ω² + 4))
```

З умови B′ = 0 (заміна x = ω²): 4 − x² = 0 ⇒ ω = √2, B_max = 2/3.

```
T₀ ≤ 0,01 / (2/3) = 0,015 с
```

**2. Дискретна ПФ ПНЧ:**

```
W_п(z) = (z − 1)/z · Z{W₀(s)/s},   W₀(s)/s = 1/s − 2/(s + 1) + 1/(s + 2)

W_п(z) = (1 − d₁)²(z + d₁) / ((z − d₁)(z − d₁²)),   d₁ = e^(−T₀) = 0,985112,  d₂ = e^(−2T₀) = 0,970446

W_п(z) = (2,2165·10⁻⁴ z + 2,1835·10⁻⁴) / (z² − 1,955557 z + 0,955997)
```

**3. Різницеве рівняння:**

```
y(n) = 1,955557·y(n−1) − 0,955997·y(n−2) + 2,2165·10⁻⁴·u(n−1) + 2,1835·10⁻⁴·u(n−2)
```

Перевірка: W_п(1) = 1 = W₀(0) — статичний коефіцієнт збережено.

## Завдання 2. Теорія стійкості дискретних систем

Розглянуто:
- характеристичне рівняння дискретної системи та загальний вигляд вільного руху x(n) = Σ λᵢ zᵢⁿ;
- умову стійкості: усі корені характеристичного рівняння лежать усередині одиничного кола, |zᵢ| < 1 (|zᵢ| ≤ 1 з одним коренем на колі — межа стійкості);
- зв'язок неперервного і дискретного часу через z = e^(pT₀): ліва півплощина переходить в одиничне коло;
- білінійне перетворення z = (1 + w)/(1 − w) (апроксимація Паде), яке дозволяє застосувати критерій Гурвіця до дискретних систем;
- аналоги критеріїв у просторі станів (|λᵢ(F)| < 1, дискретне рівняння Ляпунова FᵀPF − P = −Q) та критерій Найквіста для дискретних систем.
