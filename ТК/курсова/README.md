## Постановка

Портфель з 22 активів (по дві акції з десяти галузей + BTC і BNB) розглядається як дискретна динамічна система:

```
x_i(k+1)     = [1 + ξ_i(k)] · [x_i(k) + p_i(k) − q_i(k)],          i = 1..22
x_{n+1}(k+1) = (1 − r) · [x_{n+1}(k) − (1 + α)·Σp_i(k) + (1 − β)·Σq_i(k)]
y(k)         = Σ x_i(k)
```

Стан — кошти в кожному активі та на рахунку, керування — купівлі `p_i` і продажі `q_i`, збурення — дохідності `ξ_i`.
Комісії α = β = 0,05 %, інфляція r = 5 % річних, задаючий сигнал y*(k+j) = y(k)(1+g)^j.
Керування — MPC з рухомим горизонтом: аналітичний розв'язок `û* = −H⁻¹f` і розв'язок з обмеженнями
(без позик і коротких продажів) як задача квадратичного програмування (OSQP / ADMM).

## Структура роботи

Вступ → теоретичні основи ринку акцій і портфеля → постановка задачі керування → розв'язання (MPC, обмеження, моделі прогнозу, ПФ і стійкість) → експериментальна частина на історичних даних → висновки → додаток з кодом основних функцій. Обсяг записки — 30 сторінок, з них 6 сторінок коду.

## Висновки

За ідеального прогнозу регулятор з обмеженнями виконує будь-який план аж до 1000 % річних, тобто основна складність задачі — прогноз дохідностей. Майже вся корисна для регулятора інформація міститься в знаку прогнозу. Стандартні моделі та нейронні мережі на денних даних вгадують знак лише в ~50 % випадків, тому їхні результати пояснюються дрейфом зростаючого ринку, а не точністю прогнозу.
