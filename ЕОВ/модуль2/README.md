## Зміст роботи

**Частина I. Аналіз капіталу та основних засобів фірми**
- забезпеченість капіталом і його структура, рентабельність власного капіталу;
- коефіцієнти зносу, придатності, оновлення, вибуття, технологічної структури;
- фондовіддача, фондомісткість, фондоозброєність, рентабельність основних засобів, факторний аналіз;
- резерви збільшення випуску продукції та фондовіддачі.

**Частина II. Аналіз оборотного капіталу**
- склад, динаміка та структура оборотного капіталу;
- оборотність, тривалість обороту, рентабельність оборотних активів;
- ліквідність і власні оборотні кошти, резерви підвищення ефективності.

## Ключові результати (2023–2025 рр.)

| Показник | Значення |
|---|---|
| Загальний капітал Групи | 8 570 758 → 11 973 677 тис. грн |
| Частка власного капіталу | 76,8 % → 78,8 %, леверидж 0,27 |
| Коефіцієнт зносу основних засобів | 63,4 %, оновлення 4,7 % |
| Фондовіддача | 0,919 → 0,958 грн |
| Оборотні активи | +29,2 %, до 5 935 564 тис. грн |
| Ліквідність (покриття / швидка / абсолютна) | 2,81 / 1,74 / 0,83 |
| Рентабельність продажів | 17,2 % → 11,6 % → 9,5 % |

## Висновки

- Спільна причина зниження рентабельності власного капіталу (28,7 % → 14,1 %), основних засобів і оборотних активів — падіння рентабельності продажів: виручка зростає, але собівартість і операційні витрати зростають швидше.
- Парк основних засобів значно зношений, а вибуття випереджає оновлення.
- Напрями підвищення ефективності: контроль собівартості, спрямування надлишкових коштів на оновлення обладнання й завершення незавершеного будівництва, скорочення простроченої дебіторської заборгованості.
