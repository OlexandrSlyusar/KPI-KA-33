## Мета

Освоїти пайплайн fine-tuning готових трансформерних моделей Hugging Face Transformers і Datasets під задачу NLP, порівняти дві архітектури за якістю, швидкістю та розміром моделі, побудувати коректний експеримент (однакові спліти й гіперпараметри, фіксований seed).

**Варіант 13:** CNN/DailyMail - абстрактивна сумаризація новин, **facebook/bart-base vs t5-small**; додатково - порівняння якості «людським оком» на 5 статтях. Умова та методичка - у [task/методичка.md](task/методичка.md).

## Дані та методика

- **Датасет:** CNN/DailyMail 3.0.0 (`abisee/cnn_dailymail`), випадкові підвибірки (seed 0) - train 20000 / validation 1000 / test 2000 з 287113 / 13368 / 11490. Повний train завантажується і перемішується, бо впорядкований за джерелом (на початку - статті CNN, у validation / test - переважно Daily Mail).
- **Моделі:** `facebook/bart-base` (139,4 М, denoising-автоенкодер, byte-level BPE) і `t5-small` (60,5 М, text-to-text, SentencePiece, префікс `summarize: `), `AutoModelForSeq2SeqLM`.
- **Однакові умови:** вхід до 512 і еталон до 128 токенів, AdamW, warmup 5 % + лінійний спад lr, batch 16, 3 епохи, bf16 AMP, seed 0; lr - стандартний для кожної моделі (5e-5 для BART, 3e-4 для T5), однаковий lr перевірено в бонусі.
- **Декодування (однакове):** beam 4, 56-142 нових токенів, length penalty 2.0, no-repeat 3-грам.
- **Метрики:** F1 ROUGE-1/2/L/Lsum (`rouge-score`, стемінг) з 95 % bootstrap CI і парним bootstrap для різниці моделей; параметри, час епохи, latency генерації (batch 1) на GPU / CPU, розмір ваг; базова лінія Lead-3.
- **Середовище:** AMD Radeon RX 9060 XT (16 ГБ), PyTorch 2.14.0+rocm10.1.0, Transformers 5.22.2, Datasets 5.2.0, Python 3.12.10, Windows 11, Visual Studio 2026.

## Висновки

- **Обидві моделі перевершують Lead-3** (ROUGE-L 28.07 і 28.74 проти 24.93), але між собою майже рівні: t5-small трохи кращий, значуща лише різниця ROUGE-L (0.67 п., p = 0.004).
- **Частина переваги T5 - з попереднього навчання:** чекпойнт T5 1.0 уже бачив CNN/DM, тому zero-shot ROUGE-L 26.35 проти 23.63 у bart-base; однаковий lr (5e-5) результат T5 не змінює.
- **t5-small ефективніший:** у 2.3 раза менше параметрів, ваги 231 проти 532 МБ, епоха на 30 % коротша, на CPU у 1.7 раза швидший.
- **Оцінка «людським оком»** підтверджує близьку якість (BART кращий у 3 статтях із 5, T5 - у 2) і показує обмеження ROUGE: резюме з фактичною помилкою може отримати найвищий бал.
- Обидві моделі переважно екстрактивні, працюють лише англійською і гіршають на довгих (обрізаних до 512 токенів) статтях; beam search із забороною повторів кращий за greedy.

## Запуск

**Visual Studio:** відкрити `code/ОМСМ лаба4.pyproj` (середовище з PyTorch для ROCm/CUDA) → *Start Without Debugging* (Ctrl+F5). Програма показує стан (GPU, дані, збережені моделі, перерваний запуск) і меню:

| Режим | Що робить |
|---|---|
| 1 | Повний експеримент: bart-base і t5-small → бонус → інференс (продовжує перерваний запуск) |
| 2 | Лише основні моделі (fine-tuning, ROUGE, швидкодія, 5 статей для оцінки) |
| 3 | Лише бонус на збережених вагах (zero-shot, декодування, однаковий lr, довжина статей) |
| 4 | Інференс збережених моделей на власних прикладах (+ тексти з `my_articles.txt`) |
| 5 | Smoke-тест усього конвеєра на малих підвибірках |
| 6 | Почати повний експеримент заново |

**Пауза:** Esc або Q під час роботи зберігає контрольну точку (ваги, оптимізатор, розклад lr, порядок даних) і повертає в меню; режим 1 продовжує з того самого кроку. Автозбереження - кожні 5 хвилин.

**Командний рядок:** `python ОМСМ_лаба4.py [all | main | bonus | infer | smoke | fresh]`.

> CNN/DailyMail (~840 МБ) і моделі завантажуються з Hugging Face автоматично, відсутні Python-пакети встановлюються автоматично (PyTorch не змінюється); датасет і ваги моделей не додано до репозиторію.
