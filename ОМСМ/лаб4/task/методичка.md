### Класифікація тексту (скелет)

```python
from datasets import load_dataset
from transformers import AutoTokenizer, AutoModelForSequenceClassification, TrainingArguments, Trainer
import evaluate

# 1. Датасет
raw_datasets = load_dataset("imdb")  # замініть на свій датасет

# 2. Токенізатор
model_name = "bert-base-uncased"
tokenizer = AutoTokenizer.from_pretrained(model_name)

def tokenize_fn(batch):
    return tokenizer(batch["text"], truncation=True, padding="max_length", max_length=256)

encoded = raw_datasets.map(tokenize_fn, batched=True)
encoded = encoded.rename_column("label", "labels")
encoded.set_format("torch", columns=["input_ids", "attention_mask", "labels"])

# 3. Модель
model = AutoModelForSequenceClassification.from_pretrained(model_name, num_labels=2)

# 4. Метрика
accuracy = evaluate.load("accuracy")

def compute_metrics(eval_pred):
    logits, labels = eval_pred
    preds = logits.argmax(axis=-1)
    return accuracy.compute(predictions=preds, references=labels)

# 5. Навчання
args = TrainingArguments(
    output_dir="outputs",
    evaluation_strategy="epoch",
    num_train_epochs=2,
    per_device_train_batch_size=8,
    per_device_eval_batch_size=8,
)

trainer = Trainer(
    model=model,
    args=args,
    train_dataset=encoded["train"].shuffle(seed=42).select(range(8000)),  # можна взяти підмножину
    eval_dataset=encoded["test"].select(range(2000)),
    compute_metrics=compute_metrics,
)

trainer.train()
```

## Варіанти (датасет + завдання)

> Рекомендація: ID = (останні 2 цифри залікової) % N + 1, де N - кількість варіантів (нижче 20 варіантів).

1. **IMDB (sentiment analysis, довгі рецензії).**
   - Завдання: бінарна класифікація тональності відгуків.
   - Порівняти: `bert-base-uncased` vs `distilbert-base-uncased`.
   - Додатково: дослідити вплив `max_seq_length` (128 vs 256).
2. **SST-2 (Stanford Sentiment Treebank, короткі речення).**
   - Завдання: бінарна класифікація тональності речень.
   - Порівняти: `roberta-base` vs `distilroberta-base`.
   - Додатково: порівняти без / з попереднім lowercasing / cleaning.
3. **AG News (topic classification).**
   - Завдання: класифікація новин на 4 теми.
   - Порівняти: `bert-base-uncased` vs `distilbert-base-uncased`.
   - Додатково: обмежити розмір train-підмножини (наприклад, 10k прикладів) і подивитись на деградацію якості.
4. **Yelp Polarity (відгуки, polarity).**
   - Завдання: позитив / негатив відгуку.
   - Порівняти: `roberta-base` vs `distilbert-base-uncased`.
   - Додатково: порівняти якість на коротких vs довгих відгуках.
5. **Amazon Polarity (огляди товарів).**
   - Завдання: бінарна класифікація тональності.
   - Порівняти: `bert-base-uncased` vs `deberta-v3-base`.
   - Додатково: зробити підмножину, щоб зменшити час навчання, і обговорити, як обсяг даних впливає на результат.
6. **GLUE: MRPC (paraphrase detection).**
   - Завдання: визначати, чи є пари речень перефразами.
   - Порівняти: `bert-base-uncased` vs `roberta-base`.
   - Додатково: проаналізувати типові помилки (де моделі не погоджуються).
7. **GLUE: QQP (Quora Question Pairs).**
   - Завдання: класифікація дублікатів запитань.
   - Порівняти: `bert-base-uncased` vs `deberta-v3-base`.
   - Додатково: оцінити вплив балансування класів (undersampling / weights).
8. **GLUE: MNLI (Natural Language Inference).**
   - Завдання: класифікація entailment / neutral / contradiction.
   - Порівняти: `bert-base-uncased` vs `roberta-base`.
   - Додатково: порівняти якість на matched vs mismatched сплітах.
9. **CoNLL-2003 (NER, англійська).**
   - Завдання: розпізнавання іменованих сутностей (PER, ORG, LOC, MISC).
   - Порівняти: `bert-base-cased` vs `roberta-base`.
   - Додатково: порівняти F1 по різних типах сутностей.
10. **WikiANN (мультимовний NER, обрати 1 мову, наприклад English або Ukrainian).**
    - Завдання: NER на вибраній мові.
    - Порівняти: `bert-base-multilingual-cased` vs `xlm-roberta-base`.
    - Додатково: протестувати модель на кількох прикладах іншої мови.
11. **SQuAD v1.1 (extractive QA).**
    - Завдання: відповіді на питання за уривком тексту.
    - Порівняти: `bert-base-uncased` vs `distilbert-base-uncased` (або інші QA-моделі).
    - Додатково: порівняти якість на коротких vs довгих контекстах.
12. **SQuAD v2.0 (unanswerable questions).**
    - Завдання: QA з можливістю «немає відповіді».
    - Порівняти: `roberta-base` vs `deberta-v3-base`.
    - Додатково: проаналізувати, які типи не-відповідних питань найважчі.
13. **CNN/DailyMail (абстрактивна сумаризація).**
    - Завдання: генерувати короткий summary для новинної статті.
    - Порівняти: `facebook/bart-base` vs `t5-small`.
    - Додатково: порівняти якість «людським оком» на 5 статтях.
14. **XSum (короткі екстремальні самарі).**
    - Завдання: 1-реченнєва сумаризація.
    - Порівняти: `facebook/bart-base` vs `t5-base`.
    - Додатково: порівняти довжину та інформативність згенерованих резюме.
15. **Multi30k (EN→DE переклад).**
    - Завдання: переклад англійських речень німецькою.
    - Порівняти: `Helsinki-NLP/opus-mt-en-de` vs `facebook/mbart-large-50` (можна взяти підмножину даних).
    - Додатково: порівняти на власних реченнях (у т.ч. не з датасету).
16. **Новинна класифікація українською (UA-News / Ukrainian News Classification).**
    - Датасет: `FIdo-AI/ua-news` (Hugging Face) або Kaggle «Ukrainian News Classification» (новини українською, 5+ тематичних класів).
    - Завдання: мультикласова класифікація новин за темами.
    - Порівняти: `bert-base-multilingual-cased` vs `xlm-roberta-base`.
    - Додатково: перевірити якість окремо для коротких та довших текстів.
17. **Мультимовна класифікація новин (EN + UK).**
    - Датасет (варіант A, рекомендовано): `felixludos/babel-briefings` (Hugging Face) - вибрати підмножину новин з мовами en та uk.
    - Альтернатива (варіант B): об'єднати англомовні новини з **AG News** і українські з **UA-News** в один корпус.
    - Завдання: мультимовна класифікація тем новин.
    - Порівняти: `bert-base-multilingual-cased` vs `xlm-roberta-base`.
    - Додатково: окремо порахувати метрики для кожної мови (EN / UK) та порівняти.
18. **Короткі твіти або соціальні пости (sentiment).**
    - Датасет: **Sentiment140** (Kaggle) або Hugging Face `gxb912/large-twitter-tweets-sentiment` / `carblacac/twitter-sentiment-analysis`.
    - Завдання: бінарна класифікація тональності твітів / постів.
    - Порівняти: `distilbert-base-uncased` vs `roberta-base`.
    - Додатково: оцінити вплив попереднього очищення (видалення емодзі, URL, @user) на якість.
19. **Класифікація новин українською / російською / англійською (об'єднаний корпус).**
    - Датасет: `felixludos/babel-briefings` (Hugging Face) - вибрати новини з мовами uk, ru, en.
    - Завдання: класифікація тем новин у мультимовному налаштуванні.
    - Порівняти: `xlm-roberta-base` vs `bert-base-multilingual-cased`.
    - Додатково: порахувати метрики окремо по кожній мові та обговорити, де модель «сильніша / слабша».
20. **Будь-яка інша задача з відкритим датасетом (за погодженням з викладачем).**
    - Можливі рекомендовані датасети:
      - українські: `FIdo-AI/ua-news` (класичні новини), `FIdo-AI/ua-squad` (український SQuAD-подібний QA), `yelyah/XLSUM_UA_news` (сумаризація українських новин), набори з `ukr-detect` для токсичності / формальності тощо;
      - мультимовні: `felixludos/babel-briefings` (новини), інші HF-датасети для класифікації / NER / QA / сумаризації.
    - Завдання: самостійно сформулювати (класифікація, NER, QA, сумаризація, переклад) та обрати щонайменше 2 моделі для порівняння.
