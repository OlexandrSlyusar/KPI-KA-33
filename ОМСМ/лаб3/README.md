# Лабораторна робота №3. Автоенкодери: виявлення промислових дефектів

**Дисципліна:** Основи моделювання складних мереж (ОМСМ)
**Заклад:** КПІ ім. Ігоря Сікорського, ННІ прикладного системного аналізу, кафедра ММСА
**Група:** КА-33 · **Варіант:** 13 · **Рік:** 2026
**Виконали:** Тодощенко Євгеній, Сивенко Костянтин, Слюсар Олександр

> 🚧 **Статус:** у роботі — додано умову та методичні вказівки; код, результати та протокол буде додано після виконання.

## Мета

Реалізувати та навчити автоенкодери для відновлення, стиснення або очищення даних від шуму, а також дослідити можливості виявлення аномалій і представлення даних у латентному просторі. Порівняти щонайменше дві архітектури автоенкодерів, оцінити якість реконструкції, вплив розмірності латентного простору, складності архітектури та параметрів навчання.

## Завдання (варіант 13)

**MVTec AD — виявлення промислових дефектів.**

Обрати одну категорію об'єктів (наприклад, `bottle` або `hazelnut`). Навчити **ConvAE** та **Residual ConvAE** лише на зображеннях без дефектів. Використати reconstruction error для виявлення аномалій. Порівняти **ROC-AUC, PR-AUC та F1-score**. Побудувати **heatmap** ділянок із великою похибкою реконструкції.

**Датасет:** [MVTec AD](https://www.mvtec.com/research-teaching/datasets)

## Вимоги до виконання

### Дані та навчання

- [ ] Одна категорія MVTec AD; навчання обох моделей лише на бездефектних зображеннях
- [ ] Розбиття train / validation / test; test не використовується для вибору гіперпараметрів, порогу аномалій чи найкращої моделі
- [ ] Не менше 10 епох або Early Stopping за validation loss
- [ ] Функція втрат MSE або MAE
- [ ] Зафіксовано random seed, гіперпараметри, розміри вибірок, версії бібліотек

### Справедливе порівняння ConvAE vs Residual ConvAE

- [ ] Однаковий split, розмір входу та нормалізація
- [ ] Однакова розмірність латентного простору в основному порівнянні
- [ ] Порівнянний бюджет навчання (епохи, оптимізатор, batch size)
- [ ] Оцінювання на тих самих тестових прикладах

### Виявлення аномалій

- [ ] Anomaly score на основі reconstruction error
- [ ] Поріг визначено за validation set (за відсутності аномалій у validation — фіксований квантиль похибки нормальних зразків)
- [ ] ROC-AUC, PR-AUC, F1-score на тестовій вибірці
- [ ] Приклади правильних і помилкових прогнозів (False Positive / False Negative)
- [ ] Heatmap ділянок із великою похибкою реконструкції

### Оцінка та візуалізації

- [ ] Метрики реконструкції: MSE, MAE, PSNR, SSIM
- [ ] Графіки train loss та validation loss
- [ ] Щонайменше 10 прикладів: оригінал → реконструкція → карта похибки
- [ ] Вплив розмірності латентного простору (≥ 2 значення для однієї моделі, напр. 16 / 32 / 64)
- [ ] Латентний простір: PCA, t-SNE або UMAP
- [ ] 5 найкращих і 5 найгірших реконструкцій з поясненням причин похибок
- [ ] Таблиця порівняння: параметри (М), latent dim, метрики, час епохи, latency (пристрій, batch size)

### Що здати

- [ ] Код із читабельними секціями (дані → preprocessing → архітектура → навчання → оцінка → візуалізації → висновки)
- [ ] Збережені найкращі ваги обох автоенкодерів, демонстрація інференсу на ≥ 10 тестових зразках
- [ ] Короткий звіт (1–2 стор.): архітектури, графіки навчання, таблиця метрик, візуалізації, висновки
