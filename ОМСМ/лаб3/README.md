## Мета

Реалізувати та навчити автоенкодери для відновлення, стиснення або очищення даних від шуму, дослідити виявлення аномалій і представлення даних у латентному просторі; порівняти щонайменше дві архітектури, оцінити якість реконструкції, вплив розмірності латентного простору, складності архітектури та параметрів навчання.

**Варіант 13:** MVTec AD, категорія `bottle`. **ConvAE vs Residual ConvAE** навчаються лише на зображеннях без дефектів; дефекти виявляються за похибкою реконструкції (ROC-AUC, PR-AUC, F1), heatmap показує ділянки з великою похибкою. Умова та методичка - у [task/методичка.md](task/методичка.md).

## Дані та методика

- **Датасет:** MVTec AD / bottle, 256×256 RGB - train 178 / validation 31 (лише норма) / test 83 (20 норма + 63 дефектних: broken_large, broken_small, contamination).
- **Моделі:** ConvAE (5 × Conv 4×4 s2 + BN + LeakyReLU, векторний bottleneck) і Residual ConvAE (те саме + ResBlock після кожного рівня), без skip-з’єднань енкодер → декодер.
- **Однакові умови:** MSE, Adam lr 1e-3 + ReduceLROnPlateau, batch 16, до 400 епох з Early Stopping за val loss, flip-аугментації, AMP, seed 0; основне порівняння при z = 128, дослідження z = 32 / 64 / 128.
- **Anomaly score:** середнє top-1 % згладженої (Gaussian σ = 4) карти похибки (x − x̂)²; поріг - квантиль 0,95 score на validation (test не використовується для жодного вибору).
- **Обладнання:** AMD Radeon RX 9060 XT (16 ГБ), PyTorch 2.14.0+rocm10.1.0, Windows 11, Visual Studio 2026.

## Висновки

- **ConvAE ≈ Residual ConvAE за якістю виявлення** (z = 128): ROC-AUC 0.970 vs 0.971, PR-AUC 0.991 vs 0.992, F1 0.904 vs 0.895. ConvAE краще реконструює норму (SSIM 0.919 vs 0.909) при 7.69 М проти 12.01 М параметрів і втричі меншій latency - залишкові блоки не дають виграшу, бо якість обмежує bottleneck.
- **Помилки - лише пропуски** (FP = 0 за порогом q = 0,95): сколи ранжуються ідеально (ROC-AUC 1.000 / 1.000), найважчі - слабкі забруднення (contamination, 0.910).
- **Latent dim 32 → 128** покращує реконструкцію, але на виявлення впливає слабко; дефекти не відокремлюються в латентному просторі (PCA / t-SNE / UMAP) - працює саме похибка реконструкції.
- **Бонус:** Denoising ConvAE - найкращий (ROC-AUC 0.977, SSIM 0.924) і стійкий до шуму (PSNR 32.33 vs 30.27 дБ при σ = 0,2); Conv VAE поступається через розмиття (ROC-AUC 0.929); score за картою (1 − SSIM) підвищує ROC-AUC ConvAE до 0.986.
- **Інференс** збережених моделей на 12 тестових зображеннях: ConvAE - 12 / 12, Residual ConvAE - 12 / 12 правильних прогнозів.

## Запуск

**Visual Studio:** відкрити `code/ОМСМ лаба3.pyproj` (середовище з PyTorch для ROCm/CUDA) → *Start Without Debugging* (Ctrl+F5). Програма показує стан (GPU, дані, збережені моделі, останні результати) і меню:

| Режим | Що робить |
|---|---|

| 2 | Лише основні моделі (ConvAE / Residual ConvAE, z = 32 / 64 / 128) |
| 3 | Лише бонус на збережених вагах (VAE, DAE, шум, UMAP, параметри навчання) |
