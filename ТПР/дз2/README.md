## Умова

```
F = x1 + x2 + 2x3 + x4 → max

x1 + 2x2 + 2x3 + x4 ≤ 40          (зв'язуюче обмеження)

Блок 1 (f1):  x1 + 3x2 ≤ 30       Блок 2 (f2):  x3 ≤ 10
              2x1 + x2 ≤ 20                     x4 ≤ 10
                                                x3 + x4 ≤ 15
xj ≥ 0, j = 1…4
```

## Хід розв'язання

1. Виділено зв'язуюче обмеження та два блоки. Будь-який елемент множин допустимих розв'язків f1 і f2 подано як опуклу комбінацію їхніх крайніх точок:
   - f1: x¹ = (0; 0), x² = (6; 8), x³ = (10; 0), x⁴ = (0; 10);
   - f2: y¹ = (0; 0), y² = (10; 5), y³ = (5; 10), y⁴ = (10; 0), y⁵ = (0; 10).
2. Початковий допустимий розв'язок: Λ = [0; 0; 0].
3. На кожній ітерації розв'язуються підзадачі блоків з поточними двоїстими оцінками; крайня точка з від'ємною оцінкою Δ вводиться в базис (крок методу оберненої матриці).
4. На 4-й ітерації всі оцінки Δ ≥ 0 — розв'язок оптимальний: x_opt = 5/12·x² + 7/12·x³, y_opt = y².

## Відповідь

**x\* = (25/3; 10/3; 10; 5), F_max = 25/3 + 10/3 + 2·10 + 5 = 36 2/3**

Результат перевірено розв'язанням задачі ЛП стандартним методом.
