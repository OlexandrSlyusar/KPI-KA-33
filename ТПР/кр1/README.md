## Умова

```
F = 4x1 + x2 + 2x3 + 3x4 → max

2x1 + x2 + x3 + 2x4 ≤ 21          (зв'язуюче обмеження)

S1:  2x1 − x2 ≤ 4                  S2:  3x3 − x4 ≤ 6
     x1 + 2x2 ≤ 22                     −x3 + 2x4 ≤ 8

xj ≥ 0, j = 1…4
```

## Хід розв'язання

1. Виділено зв'язуюче обмеження та два незалежні блоки S1 (x1, x2) і S2 (x3, x4) — задача має блочно-діагональну структуру.
2. Знайдено крайні точки многогранників S1 і S2.
3. Сформовано координуючу задачу відносно ваг крайніх точок (Λ = [Λ1; λ01; λ02]).
4. Координуючу задачу розв'язано методом оберненої матриці з генерацією стовпців: на кожній ітерації за двоїстими оцінками розв'язуються підзадачі блоків, і нова крайня точка вводиться в базис, доки не виконується критерій оптимальності.

## Відповідь

**x\* = (9/4; 1/2; 4; 6), F_max = 35,5**

Перевірка: зв'язуюче обмеження виконується як рівність (4,5 + 0,5 + 4 + 12 = 21); результат збігається з розв'язком задачі ЛП стандартним симплекс-методом.
