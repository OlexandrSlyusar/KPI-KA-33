## Умова

```
F = x1 + 2x2 → min

5x1 − 2x2 ≥ 20
 x1 − 2x2 ≥ −20
 x1 +  x2 ≤ 16
 x1, x2 ≥ 0
```

## Хід розв'язання

1. Перехід від min до max: Z = −F = −x1 − 2x2 → max; обмеження «≥» множимо на −1.
2. Вводимо балансові змінні x3, x4, x5 ≥ 0 і будуємо 1-й псевдоплан.
3. Усі Δj ≥ 0 — псевдоплан задовольняє критерій оптимальності, але x3 = −20 < 0, тому план не є допустимим.
4. Напрямний рядок — x3, напрямний стовпець — A1 (θ = 1/5); після перетворення таблиці всі базисні компоненти невід'ємні.

## Відповідь

**x\* = (4; 0), F_min = 4**

Перевірка: 5·4 − 2·0 = 20 ≥ 20; 4 − 0 = 4 ≥ −20; 4 + 0 = 4 ≤ 16.
