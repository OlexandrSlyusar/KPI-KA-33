## Умова

```
F = 2x1 + x2 + x3 + 2x4 → max

x1 + x2 + 3x3 + 2x4 ≤ 20           (зв'язуюче обмеження, b0 = 20)

Блок 1:  2x1 + x2 ≤ 13             Блок 2:  5x3 − 2x4 ≤ 14
         x1 + 2x2 ≤ 14                      −x3 + 3x4 ≤ 5

xj ≥ 0, j = 1…4
```

## Розв'язання

Ідея методу — розподіл спільного ресурсу між підсистемами: y1 = x1 + x2, y2 = 3x3 + 2x4, y1 + y2 ≤ 20.

**1. Блочна задача 1:** f1(y1) = max(2x1 + x2). Вершини області: O(0; 0), B(6,5; 0), A(4; 5), C(0; 7).

```
f1(y1) = 2y1,  0 ≤ y1 ≤ 6,5
f1(y1) = 13,   y1 ≥ 6,5
```

**2. Блочна задача 2:** f2(y2) = max(x3 + 2x4). Вершини області: O(0; 0), B(2,8; 0), A(4; 3), C(0; 5/3).

```
f2(y2) = y2,              0 ≤ y2 ≤ 10/3
f2(y2) = (5y2 + 20)/11,   10/3 ≤ y2 ≤ 18
f2(y2) = 10,              y2 ≥ 18
```

**3. Координуюча задача:** max(f1(y1) + f2(y2)) при y1 + y2 ≤ 20. Ресурс розподіляється за граничною ефективністю dfj/dyj:

- блок 1 отримує y1 = 6,5 (похідна 2 > 1);
- далі похідна f1 дорівнює 0, тому весь залишок отримує блок 2: y2 = 13,5.

## Відповідь

**x\* = (6,5; 0; 61/22; 57/22), F_max = 461/22 ≈ 20,95**

Перевірка: зв'язуюче обмеження виконується як рівність (20 = 20), усі блочні обмеження виконуються; результат збігається з розв'язком задачі ЛП стандартним методом.
