## Ключові результати

- Задача 5: відношення R не є ні рефлексивним, ні симетричним.
- Задача 6: відношення R не є транзитивним за жодним із трьох способів.
- Задача 10: найбільш недоміновані альтернативи — X4 (а), X2 (б), X4 (в), X3 (г), кожна з μнд = 1, тобто чітко недомінована.

## Основні означення

```
μ(A∪B)(x) = max{μA(x), μB(x)}          μ(A∩B)(x) = min{μA(x), μB(x)}
μ(Ā)(x)   = 1 − μA(x)                  Aα = {x : μA(x) ≥ α}
сильне об'єднання: min{1, μA(x) + μB(x)}   сильний перетин: μA(x)·μB(x)
```
